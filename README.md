# BIP评估（ScalePad）

在 iPad 上离线运行的评估问卷 PWA。医生和患者共用一台 iPad：患者点选答案，需要口头作答的题由医生用数字按钮标记对错。每一次点击都实时写入 iPad 本机存储，结束后可导出 CSV / JSON。

安装与更新步骤见 [在iPad上安装.md](在iPad上安装.md)。也可以完全不用 iPad，直接在电脑上做，见下文「在电脑上使用」。

## 在电脑上使用

1. Mac 双击 `start-scalepad-desktop.command`（第一次若被拦截：右键 → 打开）；Windows 双击 `start-scalepad-desktop.bat`。没装 Python 时脚本会直接用浏览器打开 `index.html`，只是没有「追加进汇总表」按钮。会弹出一个终端窗口并自动用 Chrome 打开 `http://127.0.0.1:47815/`（断网也能用，不需要 IP 或证书）。**测试期间别关这个终端窗口。**
2. 之后的流程和 iPad 完全一样。认知任务用鼠标/键盘操作，与原 PsychoPy 程序一致；第一次请在「更多设置 > 认知任务画面尺寸校准」量一下 10 厘米的线（每台显示器各校准一次）。
3. 结果页多一个「追加进汇总表」按钮：直接把这次的数轴/点数结果追加进 `~/Desktop/numerical cognition/` 的汇总表（可改成某位患者的文件夹，会记住上次填的），不用再手动跑合并脚本。原件另存一份在 `numerical cognition/ScalePad导出/`。需要 openpyxl（`pip3 install openpyxl`）。

注意：
- 电脑上的记录存在 Chrome 里，和 iPad 上的互不相通。**地址必须一直是 `http://127.0.0.1:47815/`**，换端口或改用 `localhost` 都等于换了一个网站，之前的「最近测试」会看不到。
- 清除 Chrome 的浏览数据会删掉本机记录，每次测完照常导出 CSV / JSON。可在「更多设置 > 选择文件夹」绑定一个文件夹，答题时逐题写入（Chrome 支持）。

## 内置问卷

| 问卷 | 题数 |
| --- | --- |
| BIP A 套 / B 套｜先感知、再想象（一般选这个） | 各 336 |
| BIP A / B｜视觉心理意象（分开做时用） | 各 209 |
| BIP A / B｜视觉感知（分开做时用） | 各 127 |
| VVIQ｜视觉想象生动性 | 16 |
| PIT｜前瞻意象任务 | 40 |
| BAI｜贝克焦虑量表 | 21 |
| SDS｜抑郁自评量表 | 20 |
| DSRS｜儿童抑郁自评（儿童版） | 18 |
| SCARED｜儿童焦虑筛查（儿童版） | 41 |

另有两个**认知任务**（复刻 `~/Desktop/project` 里的 PsychoPy 程序 `数轴实验.py`、`点数比较实验.py`），见下文「认知任务」。

**BIP 题目顺序**（`presets.js` 的 `combinedSet` / `doctorFirst`）：

- A 套 / B 套：先做医生部分。最开头是朗读数字、字母、词语（患者先看过这些字，后面靠听的题才能做）；接着是医生读题的纯听题（数字、字母构建、汉字、词语）；然后出现“请把屏幕转向患者”，做其余医生判断对错的口答题（颜色名称、名人面孔识别、形态辨别、典型颜色）；之后直接进入患者自己点选的题（不再单独出“交给患者”页）。患者部分里同类题挨着、先感知再想象：看图耳朵 → 想象耳朵，空间感知 → 空间表征，时钟识别 → 想象时钟，然后是其余想象题。
- 分开做时，每卷也是医生读题 → 医生判断 → 患者点选。
- 空间感知、空间表征、时钟识别、想象时钟这四部分开始前，会先显示一页示例（`assets/examples/`，由 `tools/make_examples.py` 生成），每张图上方标出答案：空间题一张“是”一张“否”，时钟题“都在左侧”“都在右侧”“一左一右”各一张（想象时钟示例每张图上面是时间、下面是想出的钟面）。补充说明用棕色字放在图下方。所有有标准答案的选择题旁边都有一个小的灰色“不确定”按钮，选它算答错（量表和医生判断的口答题不加）。情绪问卷（BAI、SDS、DSRS、SCARED）开始前会先放一页提示：接下来是情绪问卷，没有对错。**示例至少要看 5 秒**，按钮才能点“看懂了，开始答题”（或按 Enter / D）。看过的示例不再自动出现；在本部分第一题按“上一题”（或 A）可翻回示例页。
- 题库调整顺序后，恢复以前没做完的测试仍按当时的顺序，记录不会错位。

BIP 各卷的名人题分 18–30 岁、31–60 岁两版（各 10 题），按年龄自动选择。上表题数包含两版，实际作答时只出现其中一版（少 10 题）。

**名人题无论如何全部做完**（自适应不省略）。患者没见过的人不计入正确率：
- 名人面孔识别（看照片说名字）：屏幕提示患者“没见过就说‘没见过’”。见过但说不出来 → 医生标 2（错）；没见过 → 标 **3（没见过）**（按钮上写着“3 没见过”；记录里仍存为 mark 4，和旧记录一致）。
- 名人面孔心理表征（两位名人比较）：患者不认识其中一位时点“我不知道这是谁”，医生也可按键盘 3。
- 例如 10 位名人，1 位没见过，其余 9 位答对 8 位，正确率写作 `0.89 (9)`（括号里是计入正确率的题数）。

**屏幕上的题目**：题干直接问清楚（“哪个体积更大？”“哪个城市在武汉的西边（地图左边）？”“橙子和柑橘长得有什么不一样？”“树干一般是什么颜色？”），指导语只留一句“请想象……”，字体缩小；顶部“部分”按钮只写“V 部分”，不写部分名。高矮题的选项是“高 / 长”“矮 / 扁”。

## 一次测试的流程

1. **首页填写患者信息**：编号、姓名、年龄、职业、性别、学历；确认癫痫病史、是否熟悉英文字母、名人题版本。
2. **选择量表**：上面选 **BIP A 套或 B 套**（感知 + 想象一起做）；特殊情况点「分开做」，只选感知或只选想象；下面是 VVIQ、PIT、情绪量表等其他问卷。按点击顺序作答，选择会被记住，下一位患者默认沿用。
3. **答题**：
   - 顶部「部分 ▾」可随时切换到别的部分，或「结束并出结果」。
   - 「跳过…」记录跳过原因代码（001 过于简单 / 002 太难 / 003 不熟悉内容 / 004 拒绝或疲劳 / 005 设备问题 / 009 其他），可只跳本题或跳过本部分剩余题，还可以写一句备注（存进 CSV 的 skipNote 列，结果页跳过栏也会显示）。**跳过菜单和答题屏幕上只显示代码、不写原因**，患者看不出为什么跳过；代码对照表在首页设置说明和结果页。自适应自动记为正确的题显示“已记录 A”。
   - 医生标记：**1 正确　2 错误　3 不确定**（3 不计入正确率）；名人面孔识别是 **1 正确　2 错误　3 没见过**（不计入正确率）。口答题患者只看到「请说出你的答案」，下方灰色虚线框是「医生记录 · 患者无需操作」区，按钮只显示数字。
   - **电脑键盘操作**：**A 上一题、D 下一题（← → 也行）、W 上一部分、S 下一部分**，1 / 2 / 3（主键盘或小键盘）标记，都是按一下就生效，可以快速翻题。**跳过要长按约 0.6 秒**（会记入结果，所以要长按防误触；短按会提示“跳过要长按才生效”）：**长按 Q = 001 过于简单、长按 E = 002 太难**，直接跳过本题；长按空格弹出跳过菜单，按 1–6 选其他代码、可写备注，Esc 取消。示例页上按 Enter 开始。光标在回答框里时按键会当作文字输入，按 Esc 离开回答框再按。按键和时长在 `app.js` 的 `navKeys` / `skipKeys` / `keyHoldMs`。
   - 不熟悉英文字母时，字母题自动记为 003 跳过。
   - 纯听题（数字、字母、汉字结构等）屏幕只显示「请把设备交给医生」，由医生点开题目照着读。
   - VVIQ 每 4 题一个场景，每组第一题下方有「全 1 … 全 5」快捷按钮，一次把本组 4 题记成同一分并跳到下一组；这样填的题没有逐题反应时间，JSON 记录里带 `bulkFilled` 标记。
   - 颜色名称测试的色块不自动出现，先显示灰色卡片「点击显示颜色」，点一下才显示；反应时间从色块出现时算起。
   - 机器语音读题默认关闭，答题中可用「语音：开/关」切换。
4. **结果页**：做完最后一题后先显示“评估结束，请把设备还给医生”，医生长按下方灰色按钮 1.5 秒才显示结果（从“部分”菜单点“结束并出结果”则直接显示）。分区统计（答对/计入/总题数、正确率写作 `0.89 (9)`、跳过代码）和答题指标；可导出 CSV、JSON，可「返回继续作答」，或「开始下一位患者」。

### 自适应（可选，默认关闭）

首页「自适应」选「开启」后（选择会被记住）：

- 对 BIP 各卷中有对错、超过 5 题的部分（名人题除外，名人题全部做完），先出本部分标为「难题」的题，再出其余题。
- **连对通过**：按作答顺序连续答对 5 题 → 本部分其余题自动记为正确，直接进入下一部分（之后按“下一题”也会越过这些题，所以会直接跳到下一部分）；结果页该部分注明“连续答对 5 题，N 题自动计为正确”。
- **连错停止**：按作答顺序连续答错（含标 3）4 题 → 本部分剩下的题按 002（太难）自动跳过，进入下一部分。要本部分实际做满 5 题才生效。阈值在 `app.js` 的 `adaptivePassRight` / `adaptiveMinItems` / `adaptiveStopWrong`。不看用时，做得慢但答对的人照常做完。
- 之后回头改了答案、条件不再成立，自动计分 / 自动跳过会撤销，那些题重新变成待答；也可以从「部分 ▾」进入被自动计分的题直接作答覆盖。
- 原则是数据完整优先：只在本部分结果已经明确时省略题目，看不出来就全部做完，不设总时长上限。
- 结果页每部分注明“自适应省略 N 题，约省 X 分钟”，顶部有合计；省时 = 省略题数 × 本部分实际作答的中位用时（估算）。
- 情绪量表（BAI、SDS、DSRS、SCARED）、VVIQ、PIT 和认知任务不受影响。
- 难题名单在 `presets.js` 的 `hardImageryA` 等表里，是按经验挑的（比较对象接近、答案反直觉、刺激更复杂），**积累数据后应按实际错误率调整**；也可在「问卷编辑」里逐题勾选「难题」。
- 导出 CSV 多三列：`adaptiveCredited`（1 = 自动计为正确）、`adaptiveStopped`（1 = 连错停止自动跳过）、`hardItem`（1 = 难题）；JSON 里带 `adaptive` 标记，事件流里有 `adaptive_credited` / `adaptive_revoked`。

### 大字显示

答题界面的文字都尽量放大；每部分指导语下面有一行蓝色的“→ 要做什么”（点按钮 / 大声说出答案 / 听医生读题）。带图片的题省掉指导语正文，只留题干和这一行，给图片让出位置。

### 打包发给别人（标准版 / 自适应版）

```zsh
python3 tools/build_release.py
```

在 `dist/` 生成两个电脑版（Windows、Mac 通用，内附简易说明 `README.txt`：怎么打开、按键、1/2/3 标记、跳过代码）：

- `ScalePad-电脑版.zip`：对外版，发给外部使用。自适应相关的代码、界面文字、结果说明、导出列（adaptiveCredited 等）、难题标记全部剥掉，也不带这份 README（只带 `README.txt`），看不出有自适应功能。
- `ScalePad-电脑版-内部（含自适应）.zip`：内部使用，可开启自适应。

对外版靠源码里的标记剥代码（规则写在 `tools/build_release.py` 开头）：`//@A{ … //@A}` 整段、行尾 `/*@A*/` 的行只留在内部版，`//@E …` 是对外版的替换行。**以后改自适应相关代码时记得加标记**，打包后可以解压对外版，搜一下 `adaptive`、`自适应` 确认没有漏。证书、`Scales/` 原始问卷和 iPad 专用文件（iPad 版暂停更新）不会打包进去。

### 回首页与继续测试

- **答题中回首页要长按左上角房子按钮约 1.5 秒**，轻点只会提示“长按回首页”，防止患者误触。结果页和问卷编辑页点一下即可。
- 回首页不会丢失测试。首页顶部的 **「最近测试」** 列出最近 5 次测试：
  - 未完成的可点「继续作答」，从第一道没做的题接着做；
  - 任何一次都可点「查看结果」，重新查看或导出。
- 中途退出 App、杀掉后台、iPad 重启后同样可以从「最近测试」继续。
- 从答题页或结果页回到首页时，患者信息表单会清空，避免给同一位患者误建第二份测试。
- 如果测试用到的问卷在编辑器里被改过题目数量，这次测试将无法恢复（会提示），原始记录仍保留在本机。

## 认知任务：数轴评估、点数比较评估

在量表列表的「认知任务」组里勾选。答到这一题时医生先讲指导语，再点「开始」进入全屏任务；做完自动回到答题流程。

- **流程、参数、计分与原 PsychoPy 程序一致**，不要随手修改 `tasks.js` 里的这些逻辑，否则和已有数据对不上：
  - 数轴：22 个数字随机顺序；正确位置 = −300 + (数字−1)×6（所以 100 对应 294 而不是线端 300）；总分 = 100 ×（1 − 总偏差 /（600 × 题数））。
  - 点数比较：20 题，比例 0.63/0.75/0.88；每题限时 **10 秒**（原指导语写 5 秒，原代码是 10 秒）；两边点数比值与 1 相差 ≤ 0.10 的题选哪边都算对；超时记为“是否正确 = 2”。
- **画面尺寸**：保持原程序 800×600 窗口的比例，**按比例铺满屏幕**（原程序的 14 厘米数轴太小，很多患者看不清），数字和数轴两端的 1、100 也加大了。坐标和计分仍按原程序的 800×600 像素，结果不受影响；实际画出的数轴长度记录在 JSON 的 `meta.lineCm`（准确需先在「更多设置 > 认知任务画面尺寸校准」用尺子量一下 10 厘米的线）。屏幕比原尺寸还小时会提示。
- **操作方式**：
  - 数轴：接鼠标时与原程序相同（红点跟随光标，点击确认）；触屏时手指可按在数轴下方，红点落在数轴上，左右拖动，抬起手指确认。
  - 点数比较：点屏幕左半边选左、右半边选右；接键盘时也可用 ← →。
  - 与原程序（鼠标/键盘）相比，触控会改变反应时，数轴的落点精度也可能略有差异；每次的实际操作方式（touch / mouse / keyboard）记录在 JSON 的 `meta.inputTypes` 里，合并分析时请区分设备。
- **返回**：点“开始”后先出现欢迎和说明页（约 5 秒），这时按 A、Esc 或点左下角“‹ 返回”可退回题目页，什么都不记；进入正式题目后不能返回。
- **跳过**：任务右下角的“长按跳过”按钮按住 1 秒（或长按空格 1 秒）跳过本评估，回到题目页后按 1–6 选跳过代码；长按 Q / E 1 秒直接记 001 / 002。评估结束时不再给患者显示分数（只显示“本部分完成”），分数在结果页。点数比较的点画得比原程序大（半径 5 → 8），点数和位置规则不变。
- **中止**：任务中左上角的 × 长按 1.5 秒可中止，本题不记录结果，可重新开始或跳过。
- **导出**：结果页的「导出数轴评估（xlsx）」「导出点数比较评估（xlsx）」生成与原程序格式相同的工作表（sheet 名为完成时间，表头、数据类型一致），文件名如 `数轴评估_P001_2026-10-11_14-03-22.xlsx`。
- **追加进汇总表**：汇总表是 `~/Desktop/numerical cognition/数轴评估_results.xlsx`、`点数评估_results.xlsx`。原程序的旧汇总表（`数轴实验_results.xlsx`、`点数实验_results.xlsx`）在第一次追加时会自动改成新名字，原有 sheet 都保留；旧版导出的 `数轴实验_…`、`点数实验_…` 文件也能追加。把导出文件传到 Mac 后运行：

  ```zsh
  python3 tools/merge_numerical_xlsx.py ~/Downloads/数轴评估_*.xlsx ~/Downloads/点数评估_*.xlsx
  # 追加到某位患者的文件夹：加 --dest "~/Desktop/numerical cognition/患者姓名/患者姓名pre"
  ```

  同名 sheet 已存在时会跳过，可以放心重复运行。

## 数据保存

- 每次点击立即写入 **IndexedDB**（`scalepad_live_logs_v1`），支持的浏览器另写一份 **OPFS** 副本（`ScalePad-logs/`）。开始测试前会做一次写入读回校验，失败则不允许开始。
- 「更多设置 > 选择文件夹」可额外绑定一个文件夹逐题写入（iPad Safari 一般不支持，主要用于电脑浏览器）。
- 数据只存在这台 iPad 的这个 App 里。**删除主屏幕图标，或用新地址重新安装，都等于换了一个 App，旧记录不会带过去**，删除前请先导出。
- 导出文件：
  - **CSV 结果表**：每题一行，含回答、医生标记、对错、跳过代码、用时，Numbers / Excel 直接打开。
  - **JSON 完整备份**：包含每一次点击的原始事件，用于数据分析或出问题时恢复。

| `xlsx.js` | 不依赖外部库的 xlsx 生成，格式与 openpyxl 一致 |
| `tools/merge_numerical_xlsx.py` | 在 Mac 上把导出的任务结果追加进 `numerical cognition` 汇总表 |
| `sw.js` | Service Worker，离线缓存（代码先联网、断网用缓存；图片缓存优先） |
| `assets/` | 题目图片素材 |
| `check-assets.js` | 校验题库引用的图片都存在且都在 `sw.js` 预缓存清单里 |
| `start-scalepad-desktop.command` / `serve_local.py` | 直接在这台电脑上使用（本机网页服务 + 一键追加进汇总表） |
| `start-scalepad-mac.sh` / `start-scalepad.ps1` | 在电脑上启动给 iPad 安装用的 HTTPS 服务 |
| `serve_https.py` | HTTPS 静态服务 |

## 修改后发布新版本

1. 改完代码后，把 `app.js` 里的 `buildTag` 改成新版本号（如 `2026-10-10b`），同时把 `sw.js` 里的 `CACHE_NAME` 数字加 1。
2. 改了图片素材时运行 `node check-assets.js`，确认全部通过；否则 iPad 的离线缓存会安装失败。
3. 在电脑上启动服务，让 iPad 更新（见安装文档的「更新已安装的 App」）。iPad「更多设置」底部显示的版本号就是 `buildTag`。
